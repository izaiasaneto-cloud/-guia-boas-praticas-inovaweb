# 3 sites ou aplicativos gratuitos que ajudam na produtividade ou nos estudos

1- Notion: organização de anotações, cronogramas e banco de dados de tarefas
onde cria paginas separadas de cada disciplina de faculdade escolar de ensino
que ira montar os calendários de varias provas 

2- Forest: serve para controlar o uso do celular e utiliza gamificação para
ajudar no foco do usuário para estudar para uma prova

3- Quizlet: revisar vários conteúdos que vai permitir a criação de cartões de
memorização para testes, vocabulario os idiomas e datas historicas
