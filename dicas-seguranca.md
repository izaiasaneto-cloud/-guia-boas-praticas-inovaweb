# 4 dicas de segurança e navegação segura da internet

1- vai Criar uma senha longa com frases e misture caracteres para vc Usar as combinações de 12 caracteres diferentes que vão evitar os seus dados pessoais 
Como uma recomenda onde  guia a sua segurança que vai Ajudar na sua Conta de usuário se baseando a senha na letra em maiúscula ou em uma frase para que o
seu código fique seguro.

2- Use um gerenciador de senhas para não repetir os códigos e Nunca utilize a mesma senha em serviços diferentes, pois o vazamento de um site pode comprometer todas as suas outras contas
Ferramentas criptografadas que vão armazenar senhas únicas automaticamente para que você precise memorizar apenas uma senha mestra.
 
3- Ative a autenticação em dois fatores. Essa camada vai exigir uma segunda confirmação além da senha, 
com um código enviado por aplicativo autenticador antes de liberar o acesso. 
 
4- Verifique links e evite redes Wi-Fi públicas desprotegidas. Sempre ira conferir se esse endereço no site estáva escrito corretamente 
antes de digitar dados bancários.
